# Slice & Dice Golf

**Accessories for the other 90%.** AU golf gear for weekend hackers.

🏌️ **Live at:** drop-shop-plum.vercel.app

## Brand

- **Store:** Slice & Dice Golf
- **Club:** The Hackers Club
- **Tagline:** Hit it. Slice it. Try again.
- **Palette:** Fairway Dark (#1B3A2D), Fairway Green (#2D6A4F), Midnight (#0C0C0C), Cloud (#FBFBFB), Sand (#E8DCC4)

## Tech

- **Framework:** Next.js 16 (App Router)
- **Database:** Supabase PostgreSQL (REST API)
- **Payments:** Stripe
- **Hosting:** Vercel
- **Styling:** Tailwind CSS v4

## Local Dev

```bash
npm run dev    # localhost:8085
npm run build  # production build
```

## Products

15 golf accessories (AliExpress-sourced, AU dropshipped):
- 6 Personalised items (ball stamps, towels, divot tools, markers, scorecard holders)
- 9 Standard items (towels, gloves, brushes, alignment sticks, headcovers, multi-tools)

## Deployment

`git push` only — Vercel auto-deploys from main branch.
